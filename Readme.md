# ⭐ STAR Approach – AWS S3 Automation Tool using Python Boto3

## 🟦 Situation
- Manual creation of AWS S3 buckets and file uploads was repetitive and time-consuming.
- Wanted to understand real-world cloud automation used by DevOps engineers.
- Needed hands-on experience with AWS services and Python automation.

---

## 🟦 Task
- Build a Python automation tool using Boto3.
- Automate:
  - AWS S3 bucket creation
  - File upload to S3 bucket
  - AWS connection handling
- Reduce manual cloud operations.

---

## 🟦 Action
- Used Python and AWS Boto3 SDK.
- Created reusable functions for:
  - AWS client connection
  - Bucket creation
  - File upload
  - Bucket listing
- Implemented automation workflow for S3 operations.
- Debugged real-world issues such as:
  - Variable scope errors
  - Incorrect AWS API parameters
  - File path/FileNotFound errors
  - Function argument mismatches
- Improved understanding of AWS APIs and Python exception handling.

---

## 🟦 Result
- Successfully automated AWS S3 bucket creation and file uploads.
- Reduced manual cloud management tasks.
- Gained practical experience in:
  - AWS Cloud
  - Python scripting
  - Boto3 SDK
  - API handling
  - Debugging and automation
- Improved understanding of real DevOps automation workflows.
