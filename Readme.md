# AWS S3 Automation Tool using Python Boto3

## Situation / Idea

* Identified repetitive and time-consuming manual AWS S3 operations such as bucket creation and file uploads through AWS Management Console.
* Wanted to understand real-world DevOps cloud automation and infrastructure management using Python scripting and AWS APIs.

---

## Task / Theme

* Designed and developed a cloud automation tool to automate AWS S3 operations.
* Automated:

  * S3 bucket creation
  * Bucket listing
  * File upload to S3 buckets
  * AWS service connection handling
* Focused on reducing manual cloud management tasks and improving automation workflow efficiency.

---

## Action / Actual Implementation

* Developed the project using Python and AWS Boto3 SDK.
* Integrated AWS S3 APIs using Boto3 client.
* Implemented reusable Python functions for:

  * AWS connection establishment
  * Dynamic S3 bucket creation
  * File upload automation
  * Bucket listing operations
* Used HTTP response status code validation for operation verification.
* Performed debugging and troubleshooting for:

  * Variable scope issues
  * AWS parameter validation errors
  * File handling and FileNotFound errors
  * Function argument mismatch issues
* Improved understanding of API handling, cloud automation, and Python debugging workflows.

### Tools & Technologies

* Python
* AWS S3
* Boto3 SDK
* AWS APIs
* Cloud Automation
* Exception Handling

## Result / Outcome

* Successfully automated AWS S3 bucket provisioning and file upload operations.
* Reduced manual cloud management effort through scripting and automation.
* Built reusable automation workflow for AWS S3 operations.
* Gained hands-on experience in:

  * AWS Cloud

  * API integration
  * DevOps automation concepts
  * Real-world debugging and troubleshooting
